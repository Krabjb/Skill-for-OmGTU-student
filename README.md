# Skill for OmGTU student

Локальный клиент «Контактной работы» ОмГТУ и навык для Codex. Клиент получает дисциплины, задания и вложения из учебного кабинета; навык использует эти материалы для выполнения работы и проверки проекта по требованиям преподавателя.

После отдельного входа клиент использует сохранённую сессию, поэтому обычный браузер и вкладку кабинета можно закрыть. Чтение и скачивание идут через HTTP. Для ручного входа открывается отдельное окно Chromium; если он не запускается, клиент пробует установленный Microsoft Edge. Срок действия сессии определяет портал: при её истечении потребуется войти снова.

Это самостоятельная интеграция для своего аккаунта, а не официальный сервис ОмГТУ. Наличие клиента не гарантирует, что в кабинете опубликованы все требования конкретной работы.

## Установка

Нужны Windows, Python 3.11 или новее, Git и установленный Codex. Для регистрации MCP команда `codex` должна быть доступна в `PATH`. На первом запуске установщик скачивает Python-зависимости и Chromium для входа.

Открой PowerShell:

```powershell
git clone https://github.com/Krabjb/Skill-for-OmGTU-student.git
Set-Location Skill-for-OmGTU-student
.\scripts\install.ps1
```

Установщик создаёт среду выполнения в `%LOCALAPPDATA%\OmgtuStudent\venv`, устанавливает зависимости из `requirements.lock.txt`, копирует навык в `~/.codex/skills/omgtu-student` и регистрирует локальный MCP `omgtu_student`. После установки начни новый чат Codex, чтобы навык и инструменты стали доступны.

Для первого входа:

```powershell
$omgtuPython = Join-Path $env:LOCALAPPDATA 'OmgtuStudent\venv\Scripts\python.exe'
& $omgtuPython -X utf8 -m omgtu_student auth login
& $omgtuPython -X utf8 -m omgtu_student auth status
```

Введи логин и пароль самостоятельно в открывшемся окне кабинета. Не отправляй пароль в чат. Клиент сохраняет сессию после успешного входа; окно можно закрыть после завершения команды.

Для ручной регистрации MCP используется та же среда:

```powershell
codex mcp add omgtu_student -- $omgtuPython -X utf8 -m omgtu_student serve
codex mcp list
```

## Использование в Codex

Навык можно вызвать явно:

```text
$omgtu-student Найди последнее домашнее задание по математике,
скачай все вложения и связанные требования, затем выполни работу.
```

Или обычным запросом:

```text
Зайди в контактную работу по математике и скачай последнее ДЗ.
```

Для проекта:

```text
Найди в контактной работе задание для этого проекта, привяжи его
и проверь проект по каждому пункту требований преподавателя.
```

Навык отличает ДЗ от конспектов и объявлений, загружает все вложения выбранных записей и проверяет связанные методички, шаблоны и критерии. Если неизвестен вариант или неоднозначно задание, Codex уточнит выбор. При неполной загрузке он должен назвать недостающие материалы.

Чтобы обновление выполнялось при каждом обращении к учебному проекту, добавь в его `AGENTS.md`:

```markdown
Для учебной работы используй $omgtu-student. Если проект привязан
через .omgtu, перед выполнением и проверкой обнови материалы кабинета
и проверь результат по требованиям выбранного задания.
```

Обновление сохраняет выбранную работу: новое опубликованное ДЗ не заменит её автоматически. Для перехода к другой работе укажи её явно.

## CLI

Все операции доступны без MCP. В примерах ниже `$omgtuPython` задан командой из раздела установки, а значения в угловых скобках нужно заменить результатами клиента.

```powershell
& $omgtuPython -X utf8 -m omgtu_student courses
& $omgtuPython -X utf8 -m omgtu_student assignments --course 'Математика'
& $omgtuPython -X utf8 -m omgtu_student latest --course 'Математика' --kind homework
& $omgtuPython -X utf8 -m omgtu_student download --course 'Математика' --assignment '<assignment-id>' --output '.\materials'
& $omgtuPython -X utf8 -m omgtu_student bind --course 'Математика' --assignment '<assignment-id>' --project '.'
& $omgtuPython -X utf8 -m omgtu_student sync --project '.'
```

`--course` принимает название или идентификатор дисциплины. Для нескольких работ с одинаковым названием используй идентификатор из `courses`. В `download` можно повторять `--assignment`, чтобы включить основное задание и выбранные связанные записи. Загрузка сохраняет файлы и manifest с происхождением материалов и результатами скачивания. К имени файла добавляется стабильный суффикс ссылки, чтобы одноимённые вложения не конфликтовали. Неизменённые файлы используются повторно после проверки SHA-256; изменённые сохраняются новой версией.

Клиент не исполняет и не распаковывает вложения. HTML-вложения пока отклоняются с явной ошибкой, чтобы не сохранять страницу входа как учебный файл. Чтение PDF, DOCX, старых DOC и сканов выполняет Codex подходящими средствами после загрузки; этот пакет сам не решает задачи и не извлекает формулы из документов.

Привязка проекта и материалы находятся в его `.omgtu/`; команда `bind` добавляет этот каталог в `.gitignore`. Это локальные данные, которые не следует публиковать вместе с исходниками. Отдельную директорию, переданную в `download --output`, нужно исключить из Git самостоятельно, если она находится в репозитории.

MCP предоставляет инструменты `omgtu_auth_status`, `omgtu_list_courses`, `omgtu_list_assignments`, `omgtu_latest_assignment`, `omgtu_download_materials`, `omgtu_bind_project` и `omgtu_sync_project`. Через MCP нельзя передать пароль или выполнить вход. Интеграция читает и скачивает материалы; отправка выполненных работ и сообщений преподавателям не реализована.

## Сессия и локальные данные

Данные среды выполнения хранятся вне исходного репозитория, в `%LOCALAPPDATA%\OmgtuStudent`. Сессия зашифрована Windows DPAPI для текущего пользователя. Она обычно доступна только под той же учётной записью Windows на том же компьютере; это не переносимый файл доступа. Код не требует хранения пароля.

При `login_required` выполни повторный вход:

```powershell
& $omgtuPython -X utf8 -m omgtu_student auth login
```

Чтобы удалить сохранённую сессию:

```powershell
& $omgtuPython -X utf8 -m omgtu_student auth clear
```

Не добавляй в Git сессии, реальные выгрузки кабинета, загруженные учебные файлы и данные привязки. Если портал недоступен, локальные файлы остаются полезны, но их актуальность нужно оценивать по дате последнего получения.

## Проверка и разработка

Установи пакет с инструментами разработки в отдельной Python-среде:

```powershell
python -m pip install -e '.[dev]'
python -m pytest
python -m ruff check .
```

Перед публикацией проверь подготовленные к коммиту файлы:

```powershell
python scripts/check_publish.py --staged
```

Проверка публикации дополняет просмотр `git diff --cached`: реальные HTML-страницы, cookies, имена аккаунтов и материалы из кабинета не должны попадать в публичный репозиторий. Тесты используют искусственные данные. Тесты парсера и загрузчика не заменяют проверку доступа к порталу с закрытым окном входа.

Технические основания: [локальные MCP в Codex](https://learn.chatgpt.com/docs/extend/mcp?surface=cli), [skills и MCP](https://developers.openai.com/plugins/concepts/skills), [сохранение авторизации Playwright](https://playwright.dev/docs/auth), [Windows DPAPI](https://learn.microsoft.com/en-us/windows/win32/api/dpapi/nf-dpapi-cryptprotectdata).
